# Frontend — User and Task Management System

Angular 18 (standalone components) + Bootstrap 5 client for the User and Task Management
System. See the [project root README](../README.md) for full setup instructions (database,
backend, and frontend).

## Quick Start

```bash
npm install
npm start
```

Runs on `http://localhost:4200` and expects the backend API at `http://localhost:8081/api`
(see `src/environments/environment.ts`).
